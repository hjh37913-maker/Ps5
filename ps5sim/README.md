# PS5 Interface Simulator

An original interactive reconstruction of the PlayStation 5 home interface for Android,
built with Kotlin + the Android framework Canvas (no WebView, no widgets, no servers).

- Reference target: PS5 2020 launch UI (Games/Media tabs, switcher strip, spotlight,
  "Must see" carousel, Control Center dock + activity cards).
- Target device: Samsung Galaxy A21s (720x1600, Android 12); works on any 26+ device.
- All artwork is original concept art generated by `tools/gen_assets.py`; fonts are
  Manrope and Figtree (SIL OFL).

Build (no Gradle daemon needed in CI):

```bash
bash tools/bootstrap-ci.sh && source /tmp/tc/env.sh
bash tools/build-ci.sh debug        # -> dist/PS5InterfaceSimulator-debug.apk
```

Gradle files are included for Android Studio users (`./gradlew :app:assembleDebug`).
