# Этап 0 — Техническое задание и план

**Проект:** PS5 Interface Simulator — интерактивная реконструкция интерфейса PlayStation 5
**Платформа:** Android (Samsung Galaxy A21s, 720×1600, Android 12), офлайн, без серверов
**Дата:** ноябрь 2026

---

## 1. Какие материалы нужны (и что уже собрано)

### Обязательные референсы (запрошены у вас / собраны)
| Что | Зачем | Статус |
|---|---|---|
| Главный экран PS5 (2020, Games/Media) — полный кадр 16:9 | геометрия верхней панели, полосы игр, «Must see» | есть 3 шт. |
| Главный экран с другим фокусом | проверка, что фон/лого меняются вместе с игрой | есть |
| Центр управления (открыт и раскрытый) | карточки, панель иконок, анимация | есть 2 шт. |
| Game Hub (страница игры) | размер логотипа, кнопка Play, карточки активности | есть 2 шт. |
| Библиотека игр (сетка, сортировка) | пропорции плиток, отступы, вкладки | есть 1 шт. |
| Профиль и награды | аватар, счётчики, список наград | есть 2 шт. |
| **Скриншоты интерфейса в русском языке** | точные подписи, длина строк | ❗ нужны от вас |
| **Короткое видео** перехода Home → Game Hub | длительность и кривая анимации | ❗ нужно от вас |
| **Запись звуков** системы (навигация, выбор, отмена) | характер и длительность сигналов | ❗ нужны от вас |

> Пока видео/звуков нет, длительности анимаций взяты из покадрового разбора скриншотов и
> общедоступных описаний: 130 мс (наведение), 240 мс (переход экрана), 320 мс (открытие
> Центра управления). После получения записи — заменим значения в одном файле токенов.

### Про иконки и шрифты
* Иконки нарисованы векторно по геометрии оригинального интерфейса (не растровые копии).
* Шрифт оригинала (SST) недоступен по лицензии. Используется **Manrope** (заголовки) и
  **Figtree** (текст) — обе под лицензией SIL OFL, лежат в `assets/fonts` вместе с текстом лицензии.

## 2. Какая версия интерфейса реконструируется

**Выбрана версия 2020 года (стартовая, «Games / Media»).**

Почему: именно её видно на всех собранных референсах, у неё самая узнаваемая композиция, и
она не зависит от серверных функций (Explore, Welcome Hub), которых в офлайн-приложении быть не может.

Отличия от поздних прошивок (не реконструируются): вкладка Explore, «Welcome Hub» с виджетами,
переработанный низ Главного экрана.

## 4. Техническая архитектура

```
core/
  design/   Tokens.kt (все размеры/цвета/длительности), Font.kt, Ease.kt, Strings.kt (en/uk/ru)
  engine/   Engine.kt (сцены, ввод, переходы), Ui.kt (рисование), Shapes.kt (иконки),
            Sfx.kt (звук), Scene.kt
  gfx/      Art.kt (кэш изображений), Draw.kt
data/
  model/    Game.kt, UserData.kt
  catalog/  Catalog.kt
  store/    Settings.kt, SimState.kt   — SharedPreferences, сохраняются на устройстве
ui/
  components/ Chrome.kt, SwitcherStrip.kt, Cards.kt, VirtualPad.kt
  home/ library/ hub/ launch/ media/ controlcenter/ profile/ trophies/ settings/ store/
platform/ SimulatorView.kt (один View, немедленный режим рисования)
```

Один `View` на весь интерфейс: свой цикл кадров, свой ввод, свои переходы. Никакого WebView,
никаких сетевых вызовов, полный офлайн.

## 5. Ограничения целевого устройства

| Параметр | Значение | Что сделано |
|---|---|---|
| Экран | 720×1600, ~270 ppi, 20:9 | 16:9 «сцена» вписывается по ширине, поля сверху/снизу |
| Память | 3 ГБ | изображения грузятся в уменьшенном размере и кэшируются; кадр рисуется без аллокаций |
| GPU | Mali-G52 | без шейдеров и блюра в реальном времени: «стекло» — полупрозрачные слои |
| Частота кадров | 30–60 fps | перерисовка только когда что-то движется (плюс динамический фон, если включён) |
| Android | 12 | targetSdk 35, minSdk 26; системные панели скрыты в immersive-режиме |

## 6. План визуальной проверки (без слов «похоже»)

1. **Съёмка**: приложение ставится на эмулятор (Android 10, 1280×720, та же плотность 320 dpi),
   снимается каждый экран — 13 кадров, автоматически, в CI.
2. **Сравнение**: `tools/compare.py` приводит референс и кадр к одному размеру, считает среднюю
   ошибку по пикселям (MAE) и по краям (структура), строит полосу «референс | результат | разница ×3».
3. **Геометрия**: координаты в `Tokens.kt` замерены по референсу; расхождение > 6 px (в системе 1920×1080) — дефект.
4. **Порог приёмки**: MAE ≤ 0.12 по кадру при совпадении композиции; каждый кадр просматривается
   глазами, список отклонений ведётся в `docs/VISUAL-QA.md`.
5. **Повтор** после каждой правки — до устранения всех пунктов списка.

Честное ограничение: интерфейс рисуется с нуля, поэтому побитового совпадения не будет.
Критерий — совпадение композиции, пропорций, типографики и цвета; отклонения фиксируются явно.

## 7. Что нужно от вас, чтобы двигаться дальше

1. **Скриншоты на русском** (Главный, Библиотека, Настройки) — если интерфейс должен быть русским
   по умолчанию. Сейчас по умолчанию английский, переключается в Настройках.
2. **Видео перехода** (5–10 секунд, Home → Game Hub) — уточнить длительность и кривую.
3. **Любые ваши фото экрана PS5** с телефона — даже с бликами: они уточняют оттенки.

Ничего из этого не блокирует работу: приложение уже собирается в APK, все экраны рисуются.
